# NetGuard AI: Network Intrusion Detection System

NetGuard AI is a machine learning project that classifies network flow records as either **Benign** (normal activity) or **Attack** (malicious activity) using the CIC-IDS2017 dataset.

The project is implemented as an end to end Google Colab notebook comparing two approaches:
1. **Random Forest Classifier** (baseline ensemble model)
2. **Multi Layer Perceptron** (deep feedforward neural network)

## Dataset

This project uses the **CIC-IDS2017** dataset from the Canadian Institute for Cybersecurity (University of New Brunswick).

* **Source**: Streamed from Hugging Face (`muzom/CIC-IDS2017`).
* **Sample size**: 200,000 network flow records.
* **Format**: Tabular bidirectional network flow statistics generated by CICFlowMeter.
* **Target classes**: Grouped into binary labels:
  * `0` = Benign
  * `1` = Attack (includes DoS, DDoS, PortScan, Brute Force, and Web Attacks)

### Key Features Used
* Flow Duration
* Total Forward and Backward Packets
* Flow Bytes/s and Flow Packets/s
* Flow Inter-Arrival Time (Mean and Standard Deviation)
* Packet Length Statistics (Mean, Standard Deviation, Max, Min)
* TCP Flag Counts (SYN, ACK, PSH, RST)
* Initial Window Bytes (Forward and Backward)

---

## Pipeline

1. **Data Ingestion**: Streaming 200,000 records from Hugging Face without storing the full multi gigabyte dataset on disk.
2. **Label Encoding**: Consolidating multi-class attack categories into a binary target.
3. **Cleaning**: Replacing infinite values (`+inf`, `-inf`) and missing numbers with column medians.
4. **Feature Selection**: Filtering out non-predictive identifiers (IPs, timestamps) and keeping 24 numerical flow metrics.
5. **Split & Scale**: 80/20 train/test split with stratification, normalized using `StandardScaler` fitted strictly on training data.
6. **Modeling**:
   * **Random Forest**: 100 estimators, max depth 20, parallel execution on CPU.
   * **Neural Network (MLP)**: 3 hidden layers (128 -> 64 -> 32) with ReLU activation, Batch Normalization, Dropout (0.3 and 0.2), and Sigmoid output. Trained with Adam optimizer and binary cross-entropy loss.
7. **Evaluation**: Measuring accuracy, precision, recall, F1 score, confusion matrices, and training curves.
8. **Inference Demo**: Interactive prediction function running on individual test flow records.
